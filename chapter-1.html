CHAPTER 01 · 从零开始

最简 Agent Loop：循环是第一性原理

这一章我们什么都不装，只写一个裸的循环。理解"思考→行动→观察"如何转起来，是读懂一切 Agent 框架的地基。

01本阶段目标

学完你应该能

  • ✓说清 Agent 最小循环的三要素：思考、行动、观察
  • ✓亲手写一个能对话、能停止的裸循环
  • ✓明白"上下文历史"在循环中的角色

02原理：一个循环是怎么转起来的

大模型本身是无状态的——它不知道上一轮说了什么。所以 Agent 必须自己维护状态，并把"每一次交互"组织成一个闭环。

最简的闭环只有四步：接收用户输入 → 让模型思考 → 把结果作为行动输出 → 把输出写回历史（观察）→ 回到顶部。注意：这一章还没有任何"外部工具"，"行动"就是输出文本本身。

把循环画出来，你就理解了后面所有框架（LangChain、OpenAI Agent 等）的本质——它们只是在循环的不同节点上挂更多能力。
flowchart TD
    A[用户输入] --> B[思考：llm_reason]
    B --> C[行动：print]
    C --> D[观察：写回历史]
    D --> E{继续}
    E -->|是| B
    E -->|否| F[结束]

03最小可运行代码

# loop.py — 阶段 01：只有 思考→行动→观察，没有任何工具
def llm_reason(messages):
    """占位：调用大模型，返回回复文本。
    真实环境中，这里替换为一次 API 调用。"""
    return "（模型的原始回复）"

class Agent:
    def __init__(self, model="gpt-4o-mini"):
        self.model = model
        self.history = []            # 观察区：已发生的对话

    def loop(self):
        while True:                  # 循环 = 主轴的转动
            user = input("你 > ").strip()
            if user in {"exit", "quit"}:
                break
            self.history.append({"role": "user", "content": user})

            reply = llm_reason(self.history)   # ① 思考
            print("Agent >", reply)            # ② 行动（本阶段=输出文本）
            self.history.append(               # ③ 观察：写回历史
                {"role": "assistant", "content": reply})

Agent().loop()

逐行对照三要素：

  • 思考＝llm_reason(history)——一次模型调用，只负责"想"。
  • 行动＝print——本阶段唯一动作，就是把想法说出去。
  • 观察＝history.append——把发生的事记下来，供下一轮思考使用。
为什么"历史"这么重要？因为模型无状态。删掉 history，Agent 就变成每轮"失忆"的复读机，这正是很多"看起来不聪明的 Agent"的病根。
