CHAPTER 00 · 从这里开始

为什么要从零手写一个 Agent？

本教程不是教你怎么调用现成框架，而是带你从一行代码开始，亲手把"智能体"拆开再装回去——每一步只加一个零件，看清底层原理。

01学习目标

本阶段你将理解

  • ✓Agent 到底由哪几个最小零件组成
  • ✓Harness 是什么、为什么需要一个"执行层"
  • ✓整套教程的学习路径与每章新增的能力

02先建立直觉：Agent = 循环

抛开所有营销话术，一个智能体最本质的形态，是这样一个循环：接收输入 → 思考 → 行动 → 观察结果 → 再思考。它像一台机器里的主轴，不停地转，直到得出答案或到达上限。

很多新手一上来就接触 LangChain、OpenAI 的 Agent SDK，看到的是封装好的黑盒。等你真遇到诡异的报错、想定制行为时，才发现自己完全不知道里面发生了什么。本教程的立场很直接：不读懂循环，就不配用框架。

Harness（英文原意"马具/线束"）在 Agent 语境里指承载和控制这个循环的执行层：它负责跑循环、调度工具、管理状态、加载插件。你可以在后面阶段逐步把 Harness"长"出来。

04怎么使用这套教程

  • 左侧目录按顺序排列，建议从头到尾走一遍，每章只新增少量代码。
  • 每章包含：目标 → 原理 → 流程图 → 最小代码 → 与上一版的差异 → 运行输出 → 思考题。
  • 代码都是可运行的 Python 伪实现，用最小的篇幅讲清机制；动手在本地跑一遍效果最好。
  • 绿色圆点标记你已经完成的章节，进度会在底部累积。
