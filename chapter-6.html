CHAPTER 06 · 让执行可追踪

状态管理：把每一步的 中间结果留下来

现在的 Harness 跑完就"忘了过程"。状态管理让每一步的思考、工具结果、位置都被记录，支持断点续跑与事后复盘。

01本阶段目标

学完你应该能

  • ✓理解"状态"是 Harness 运行过程的完整快照
  • ✓用 Step 记录 追踪每一步（思考/工具/结果）
  • ✓实现简单的断点续跑：从某一步恢复，不重头再来

02原理：状态 = 过程的可回溯快照

真正的 Agent 应用很少"一把梭"。如果第 20 步崩了，或用户想回看"它到底经历了什么"，没有状态管理就无从谈起。

我们把 Harness 的运行过程抽象成 Step 序列：每一步记录 类型（思考 / 工具 / 回答）、输入、输出、序号。这些 Step 组成一份可序列化的 状态。有了状态，就能暂停 → 序列化 → 恢复，也能在恢复时跳过已完成的步骤。

状态管理是"可观测性"和"工程化"的地基——下一章的观测面板、最后一章的部署，都建立在状态之上。

# state.py — 阶段 06：Harness 状态管理
import json

class Step:
    """运行中的一步：类型、输入、输出、序号。"""
    def __init__(self, kind, **payload):
        self.kind = kind          # think / tool / answer
        self.payload = payload
    def to_dict(self):
        return {"kind": self.kind, **self.payload}

class HarnessState:
    """Harness 运行过程的可序列化快照。"""
    def __init__(self):
        self.steps = []           # 已执行的步骤
        self.pending = []         # 尚未执行的输入
        self.cursor = 0           # 当前推进位置

    def record(self, step: Step):
        step.index = len(self.steps)
        self.steps.append(step)

    def snapshot(self) -> str:
        return json.dumps({
            "cursor": self.cursor,
            "steps": [s.to_dict() for s in self.steps]})

    @classmethod
    def load(cls, text: str):
        """从快照恢复状态（断点续跑）。"""
        data = json.loads(text)
        st = cls(); st.cursor = data["cursor"]
        for d in data["steps"]:
            kind = d.pop("kind"); st.steps.append(Step(kind, **d))
        return st

class Harness:
    def __init__(self, agent, max_steps=10):
        self.agent = agent; self.tools = {}
        self.max_steps = max_steps
        self.state = HarnessState()   # Harness 持有状态

    def run(self, user_input):
        # 若是恢复：跳过已完成的步骤，从 cursor 继续
        self.state.pending.append({"role": "user", "content": user_input})
        while self.state.cursor < self.max_steps:
            item = self.state.pending[self.state.cursor]
            out = self.agent.reason([item], self.tools)
            if out.get("tool_call"):
                name, args = out["tool_call"]
                result = self.tools[name](**args)
                self.state.record(Step("tool", name=name, args=args,
                                       result=result))
            else:
                self.state.record(Step("answer", text=out["text"]))
                return out["text"], self.state.snapshot()
        return "已达最大步数", self.state.snapshot()
  • Step：每一步都被结构化记录，类型、输入、输出一目了然。
  • HarnessState：持有步骤与游标，snapshot() 输出 JSON。
  • 断点续跑：load() 恢复后从 cursor 继续，不重头再来。
