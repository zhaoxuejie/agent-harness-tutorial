CHAPTER 04 · 可插拔的能力

Harness 插件：按需加载，不臃肿

工具越加越多，Harness 会越来越胖。插件机制让能力按需挂载：用哪个加载哪个，还能在运行期发现能力清单。

01本阶段目标

学完你应该能

  • ✓理解插件＝"一组能力 + 一个入口钩子"
  • ✓让 Harness 支持 register / load 插件
  • ✓学会把能力清单暴露给模型（工具选择的前提）

02原理：插件 = 能力包 + 钩子

一个插件本质上是一个能力包：它知道自己提供哪些工具、需要哪些初始化参数。Harness 通过统一的 钩子（一个 install(harness) 方法）把能力挂到执行层上。

这样做有三个好处：隔离（插件互不干扰）、按需（用哪个装哪个）、可发现（Harness 能把已装插件的能力清单喂给模型，让模型知道"现在能调用什么"）。

真实框架（如各种 Agent SDK 的插件体系）就是把这个思想工业化了：声明能力 → 校验 → 挂载 → 暴露 schema → 供模型选择。

03最小可运行代码

plugins.py · 阶段 04
# plugins.py — 阶段 04：给 Harness 加插件机制
class Harness:
    def __init__(self, agent, max_steps=10):
        self.agent = agent
        self.max_steps = max_steps
        self.tools = {}                 # 插件工具并入这里
        self.history = []

    def register_plugin(self, plugin):
        """钩子：让插件把能力挂到 Harness 上。"""
        plugin.install(self)            # 调用插件入口

    def tool_schema(self):
        """暴露能力清单，供模型决定调用哪个工具。"""
        return {name: {"doc": fn.__doc__}
                for name, fn in self.tools.items()}

    def execute_tool(self, name, args):
        return self.tools[name](**args)

    def run(self, user_input):
        self.history.append({"role": "user", "content": user_input})
        step = 0
        while step < self.max_steps:
            step += 1
            out = self.agent.reason(self.history, self.tool_schema())
            if out.get("tool_call"):
                name, args = out["tool_call"]
                try:
                    result = self.execute_tool(name, args)
                except Exception as e:
                    result = f"ERROR: {e}"
                self.history.append({"role": "tool",
                                     "name": name, "content": result})
                continue
            return out["text"]
        return "已达最大步数，强制结束。"

# ---- 插件定义：计算能力包 ----
class CalculatorPlugin:
    """计算器插件：只提供 calculate 工具。"""
    def install(self, harness):
        def calculate(expr):
            """计算数学表达式。"""
            return str(eval(expr))
        harness.tools["calculate"] = calculate

# ---- 插件定义：时间能力包 ----
class TimePlugin:
    """时间插件：只提供 current_time 工具。"""
    def install(self, harness):
        from datetime import datetime
        def current_time(_unused=""):
            """返回当前 ISO 时间。"""
            return datetime.now().isoformat()
        harness.tools["current_time"] = current_time

# ---- 按需组装 ----
h = Harness(agent=Agent(), max_steps=8)
h.register_plugin(CalculatorPlugin())   # 只装计算器
h.register_plugin(TimePlugin())         # 再装时间
print(h.tool_schema())                  # 模型可见的能力清单
  • 钩子统一：每个插件实现 install(harness)，Harness 只认这一个入口。
  • 按需：不想要的插件根本不注册，工具表里就没有它。
  • 可发现：tool_schema() 把当前能力喂给模型，模型才知道"可以调什么"。
