CHAPTER 05 · 别让 Agent 失忆

记忆模块：短期记忆与上下文的艺术

上下文一长，模型就"塞不下"或"记不清"。记忆模块负责：保留关键信息、压缩旧对话、在需要时把记忆送回循环。

01本阶段目标

学完你应该能

  • ✓区分"对话历史"与"记忆"：前者原样保留，后者被提炼
  • ✓给 Harness 挂一个 Memory 模块（截断 + 摘要）
  • ✓理解"记忆"如何作为额外上下文注入循环

02原理：记忆 = 截断 + 摘要 + 注入

模型有上下文窗口。对话越长，要么放不下，要么中间的细节被"淹没"。记忆模块在 Harness 里做三件事：

  • 截断：只保留最近 N 条原始消息，旧的移出窗口。
  • 摘要：把被移出部分压缩成一段"长期记忆"（可以是一次独立的模型调用）。
  • 注入：每次思考前，把 [长期摘要] + [最近历史] 拼起来给模型。
短期记忆＝最近原始消息；长期记忆＝被压缩的摘要。Harness 是这两者的"调度员"，决定每轮送什么进窗口。

03最小可运行代码

memory.py · 阶段 05
# memory.py — 阶段 05：给 Harness 挂记忆模块
class Memory:
    """短期记忆 + 长期摘要。"""
    def __init__(self, keep=6):
        self.keep = keep           # 保留最近消息条数
        self.recent = []           # 短期：最近原始消息
        self.summary = ""          # 长期：被压缩的摘要

    def add(self, message):
        self.recent.append(message)
        if len(self.recent) > self.keep:
            self._summarize_overflow()   # 挤出的部分变成摘要

    def _summarize_overflow(self):
        dropped = self.recent[:-self.keep]
        self.recent = self.recent[-self.keep:]
        # 真实系统里，这里用一次模型调用压缩 dropped
        self.summary += "（" + "；".join(
            m["content"][:20] for m in dropped) + "）"

    def context(self):
        """拼出送进模型的上下文：摘要 + 最近历史。"""
        blocks = []
        if self.summary:
            blocks.append({"role": "system",
                           "content": "长期记忆: " + self.summary})
        return blocks + self.recent

class Harness:
    def __init__(self, agent, memory=None, max_steps=8):
        self.agent = agent
        self.memory = memory or Memory()
        self.tools = {}
        self.max_steps = max_steps

    def run(self, user_input):
        self.memory.add({"role": "user", "content": user_input})
        step = 0
        while step < self.max_steps:
            step += 1
            out = self.agent.reason(self.memory.context(), self.tools)
            if out.get("tool_call"):
                name, args = out["tool_call"]
                result = self.tools.get(name, lambda **k: "未知")(**args)
                self.memory.add({"role": "tool",
                                 "name": name, "content": result})
                continue
            self.memory.add({"role": "assistant", "content": out["text"]})
            return out["text"]
        return "已达最大步数。"
  • Memory 接管了历史，Harness 每轮从 memory.context() 取上下文。
  • 溢出即压缩：最近消息超过 keep，挤出的部分被折叠成摘要。
  • 注入：模型每次思考都同时看到"长期记忆摘要 + 最近历史"。
